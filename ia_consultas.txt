Prompts utilizados para la creación del proyecto:

1. Prompts para el Carrusel de Imágenes (Vanilla JS):
- "Escribe el código en JavaScript (Vanilla) para un carrusel de imágenes. Debe tener un botón de siguiente, uno de anterior, y puntos indicadores (dots) abajo. Necesito que el código esté estructurado en funciones modulares como cambiarImagenSiguiente(), cambiarImagenAnterior() y actualizarDOMCarrusel()."
- "Añade un intervalo automático al carrusel para que pase a la siguiente imagen cada 5 segundos."

2. Prompts para Validación de Formularios y Arreglo de Usuarios:
- "Necesito un código en JavaScript puro para validar un formulario de registro. Debe tener campos de usuario, email, contraseña y confirmar contraseña. Asegúrate de que el email tenga un formato válido mediante una expresión regular y que la contraseña tenga mínimo 8 caracteres por seguridad. Las contraseñas deben coincidir."
- "Quiero guardar los usuarios registrados en localStorage. ¿Cómo puedo crear una estructura de datos que use un arreglo (array) vacío inicialmente y luego le haga push a cada nuevo objeto de usuario usando funciones modulares como guardarUsuario() y buscarUsuario()?"
- "Crea la función modular validarLogin(event) que verifique si el correo y la contraseña ingresados en el formulario de inicio de sesión coinciden con alguno de los usuarios guardados en el arreglo del localStorage."
